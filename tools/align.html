Circuit alignment tool

Dev-only, not part of the built app. Loads a circuit's real data.js over HTTP, so serve the repo root (e.g. python3 -m http.server) and open this via /tools/align.html.

Drag a small dot to reshape the line. Drag a big pin to move a corner — it snaps onto the nearest existing line point if close, or inserts a new line point at the exact drop location otherwise. Corners are always representable as rl(idx), matching the app's data format.
